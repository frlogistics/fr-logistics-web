Bulk Upload

Upload multiple orders at once from a CSV file. Each row is one item — orders with several SKUs use one row per SKU sharing the same order number.

1. Download the template

Use this template to format your file. UTF-8, comma-separated, maximum 500 rows per upload.

Show column reference

Format: ShipStation standard export (47-column layout). You can upload the file you already export from ShipStation — no reformatting needed.

Required columns: Order #, Recipient Full Name, Address Line 1, City, State, Postal Code, Country Code, Item SKU, Item Quantity

Optional columns we use: Recipient Phone, Buyer Email, Address Line 2, Shipping Service, Notes to the Buyer, Item Name / Title, Item Unit Price

Buyer Email = your END CUSTOMER's email. It is where the carrier's shipping, out-for-delivery and delivery notices go, with the link where the customer can sign digitally or change the delivery. Strongly recommended.

Address Line 2: only a real apartment, suite, unit or floor. Leave it blank for a house — values like "N/A", "House" or "-" are removed automatically because carriers read them as a wrong unit number.

Notes: Country Code accepts "United States" or "US". Item Quantity must be 1 or more. For an order with multiple items, repeat the Order # on each row with different Item SKU. The other 32 ShipStation columns (Order Total, Buyer info, weights, etc.) are accepted but ignored.

How it works. Before shipping, an order whose address does not pass the carrier's validation is held and shown here: confirm it if it is right (for example, a house with no apartment number) or correct it, and it ships. After shipping, we follow every package; when the carrier reports a problem we email you and the case appears here. If we do not receive a decision within 2 business days, the package is left to return and goes back to your inventory. Carrier charges for any action are billed at carrier cost plus the agreed percentage.
