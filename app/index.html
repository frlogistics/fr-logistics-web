Bulk Upload

Upload multiple orders at once from a CSV file. Each row is one item — orders with several SKUs use one row per SKU sharing the same order number.

1. Download the template

Use this template to format your file. UTF-8, comma-separated, maximum 500 rows per upload.

Show column reference

Format: ShipStation standard export (47-column layout). You can upload the file you already export from ShipStation — no reformatting needed.

Required columns: Order #, Recipient Full Name, Address Line 1, City, State, Postal Code, Country Code, Item SKU, Item Quantity

Optional columns we use: Recipient Phone, Address Line 2, Shipping Service, Notes to the Buyer, Item Name / Title, Item Unit Price

Notes: Country Code accepts "United States" or "US". Item Quantity must be 1 or more. For an order with multiple items, repeat the Order # on each row with different Item SKU. The other 32 ShipStation columns (Order Total, Buyer info, weights, etc.) are accepted but ignored.
